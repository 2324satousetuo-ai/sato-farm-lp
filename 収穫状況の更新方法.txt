【収穫状況・よくある質問の更新方法】佐藤農園LP

■ いちばん簡単なやり方（VSコード）
1. 原稿\LP.md を開く（英語は 原稿\LP-en.md）
2. 「収穫状況」の2行、または「よくある質問」の答えを直す
3. コマンドパレット（Ctrl+Shift+P）→ Tasks: Run Task →「サイトに載せる」
   写しだけ見るときは「原稿を写す（まだ送らない）」

■ 収穫の書き方
- 収穫しました　にんにく・キャベツ・じゃがいも・玉ねぎ・トマト
- 収穫中です　キュウリ・なす・ニンジン

英語（原稿\LP-en.md）
- Harvested　Garlic / Cabbage / Potato / Onion
- Currently harvesting　Cucumber / Tomato / Eggplant

・野菜は「・」またはカンマ、スラッシュで区切る
・日本語と英語の両方を直す

■ FAQの書き方
### 現在、何が買えますか？

現在、じゃがいもOKです。次は、秋の大根・白菜です。

・「###」が質問、空行のあとが答え
・項目を足す・消す・並べ替えるとそのままサイトへ写る

■ ほかのやり方（収穫だけ、質問に答えて直す）
1. 「収穫状況を更新.bat」をダブルクリック
2. 出てきた質問に、テキストで答える
3. 最後に y を押す → 原稿と日本語・英語のLPが更新される

■ 関連ファイル
・原稿/LP.md … 日本語の正本
・原稿/LP-en.md … 英語の正本
・scripts/publish-lp.mjs … 原稿をHTMLへ写す
・scripts/update_harvest.py … 質問形式の更新
・data/harvest.json … 収穫内容の保存先
・index.html … 日本語LP
・index-en.html … 英語LP

■ 公開について
「サイトに載せる」は GitHub へ送ります。
「原稿を写す」だけなら、まだ Web には出ません。
