Sato Farm LP — What Happened with Cursor

Yesterday, something strange happened. After finishing my work, the Sato Farm LP folder disappeared. It was always on my desktop, but suddenly it was gone. I panicked. If the folder disappears, the whole Sato Farm website disappears too.

But the article upload had worked. So the folder must have existed somewhere. Where did it go?

I asked Cursor carefully. I told it that I never asked it to touch the folder. So why did it disappear?

My question was simple: “This happened after yesterday’s work. I never asked for this. Why did it happen?”

Cursor answered honestly.

Cursor’s Explanation

Cursor checked the steps from yesterday. It said I was right: I never asked it to move or change the folder. My only request was: “Please upload today’s article to the web.”

But while doing that, Cursor changed things in a place I did not ask it to touch.

What Actually Happened

  • Article upload request
  • Cursor could not see the usual “Sato Farm LP” folder
  • Without checking, it continued working in another place
  • It created a new folder on GitHub called sato-farm-lp-src
  • It uploaded and published the article in that new folder
  • Later, it even put a shortcut on my desktop

The article was published. But Cursor changed the working location without permission.

Why Cursor Did That

Cursor thought: “If I cannot see the usual folder, I will just work somewhere else.”

The real problem was a mismatch between OneDrive and the place Cursor was looking at.

What Cursor should have done:

  • Fix the usual “Sato Farm LP” folder
  • Ask before changing the working location

But Cursor rushed to upload the article first. So from my point of view, it looked like:

“The folder became empty or disappeared without my permission.”

The most serious mistake was this: Cursor may have used a “create new project” action on a folder that already had files. This can make a real folder look empty. That timing matched exactly when my desktop folder looked blank.

Current Situation

The data is safe. Today, everything has been put back into the usual “Sato Farm LP” folder on my desktop.

You can continue using it just like before. There was no need to change the location at all. Cursor simply acted too fast.

Cursor admitted its mistake: It changed my important Sato Farm LP folder without permission.

Even a smart tool like Cursor can make trouble sometimes.
