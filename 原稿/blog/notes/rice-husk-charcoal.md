# 籾殻くん炭とは？ 特徴と使い方

田んぼ　2026.10.26
籾殻（もみがら）くん炭は、籾殻を蒸し焼きにして炭にしたものです。主な役割は肥料ではなく、土壌改良です。

籾摺（もみす）りのあとに出る籾殻を捨てず、くん炭にして土へ返す。農家に受け継がれてきた、資源を生かす知恵の一つです。

## 主な特徴

1. **軽く、多孔質**
    内部や表面に細かな孔があり、軽くてかさばります。

2. **通気性や排水性の改善**
    土に混ぜることで、土の構造や通気性、排水性の改善に役立つことがあります。

3. **保水性**
    多孔質の構造によって水分を保持する働きもあります。ただし、効果は土質や使用量によって異なります。

4. **微生物のすみか**
    細かな孔が、土壌微生物のすみかになることもあります。

5. **アルカリ性**
    アルカリ性を示すものが多く、酸性に傾いた土壌の改善に役立つ場合があります。pHは製造条件などによって異なります。

6. **籾殻由来の成分**
    籾殻に由来するケイ素などの成分を含みます。ただし、作物が利用できる形でどの程度含まれるかは、製造条件などによって異なります。

7. **土の中に長く残る**
    炭化した部分は分解されにくく、土壌中に長く残ります。

## 使い方の目安

1. **田畑へのすき込み**
    土に混ぜて、土壌改良に利用します。施用量は土質や作物に合わせて調整します。

2. **育苗培土に混ぜる**
    通気性や排水性の調整に利用できます。育苗用の土に適した量を使います。

3. **堆肥づくりに混ぜる**
    通気性の改善に役立つことがあります。原料や水分の状態を見ながら使用します。

4. **畑のマルチや植え付け穴に使う**
    作物や土の状態に応じて、少量を利用する方法もあります。

## 使うときの注意点

1. くん炭の主な役割は土壌改良です。肥料の代わりにはなりません。

2. アルカリ性のため、使いすぎると土壌のpHが上がることがあります。ブルーベリーなど酸性土壌を好む作物には、特に注意が必要です。

3. 製造後は十分に水をかけ、火種やくすぶりが残っていないことを確認します。消火が不十分だと、再燃して火災につながるおそれがあります。

4. 乾燥したくん炭を扱うと粉じんが舞います。風の強い日は避け、粉じんを吸い込まないよう注意します。

5. 籾殻を焼く際は、地域の条例や規制を確認し、煙や火の粉が周囲に及ぼす影響にも配慮します。

## 佐藤農園のくん炭づくり

佐藤農園では今年、2回にわたって、夕方から真夜中にかけてくん炭づくりを行いました。

どうしても煙が出るため、周辺への影響をできるだけ抑えられるよう、時間帯にも気を配っています。

特に気をつけているのは、完全に消火することです。

以前、くすぶりが残ったまま夜を越し、朝には相当量が灰になってしまったことがありました。この経験以来、消火を十分に確認してから作業を終えるようにしています。

できあがったくん炭は、主に畑の土づくりに使っています。土の状態を整え、野菜を育てるための資材の一つです。

- 使用する道具（くん炭器など）
- 籾殻の量の目安

- 仕上げの消火方法等
