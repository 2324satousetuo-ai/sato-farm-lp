# Getting Rid of the Daily Hassle: A System That Took Two Months to Build

Random Thoughts　August 27, 2026


On the Sato Farm website, I have been updating both the Japanese and English versions of my articles almost every day.

But I noticed something.

The many steps needed to upload each new article to the website were using up a large part of my Cursor Pro usage.

At this rate, it would be difficult to keep doing this for a long time because of the cost.

So I started thinking:

**Is there a better and easier way to publish my articles?**

That was the beginning.

Naturally, I decided to ask Cursor Pro to help me build a system for this.

Looking back now, it seems like a simple feature that should have been possible.

But it took about two months of trial and error to finally reach this version.

That is the honest truth.

And the final system is surprisingly simple.

1. Put the Japanese article in `原稿/blog/notes/`
2. Put the English version, with the same file name, in `原稿/blog-en/notes/`
3. Double-click `サイトに載せる.cmd` in the folder

That's it.

Everything else is done automatically, and the Japanese and English versions are updated together.

A system that took two months to build ends with just **one double-click**.

It took a long way to get here.

But now, I am free from the daily manual work.

From now on, I hope to use this system to keep sharing my stories and updates more easily and smoothly, without making the daily work a burden.
